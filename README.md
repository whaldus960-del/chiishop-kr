# 포코쿠지 (POKO KUJI)

치이카와 감성의 **4개 시리즈 × 진열대형 상세 뽑기** 모바일 웹 데모입니다.
포코쿠지 시그니처 테마의 4열 진열대(등급 스티커 라벨·실시간 확률·밀랍 실링 완판 도장) 상세 화면과
시리즈별 **3박스**(박스당 99장) 교체, `x1 / x5 / x10 / ALL` 뽑기, 진열장·묶음 배송·사장님 모드를 담았습니다.

- 단일 파일(`index.html`)로 동작하며 외부 CDN·폰트·이미지에 의존하지 않습니다. (모든 일러스트는 인라인 SVG)
- 모바일 기준 420px 프레임, 데스크톱에서는 중앙 정렬로 표시됩니다.
- 결제·배송은 **데모로만** 동작하며 실제 청구나 발송은 없습니다.
- 상태는 메모리에만 있고 새로고침하면 초기화됩니다.

## 2026-11-28 7차 — 마이페이지 '포코 5단계 진화 + 초호화 테두리' (v12)

## 실제 이치방쿠지 「くじ券」 티켓 — 두꺼운 종이 뜯기 (2026-11-28 v4)

세로 카드(봉투) 모양이던 연출을, 실제 일본 이치방쿠지 종이 티켓(一番くじ くじ券)의 생김새로 전면 교체했습니다.
실물 사진과 공식 구조도(外側·内側)를 확인해 형태·인쇄 요소를 맞췄습니다.

**실물에서 확인한 구조**

- 크림·크래프트 종이의 **가로형(약 1.5:1) 2겹 티켓**. 왼쪽에 **반치(半券) 세로 띠 + 미싱선**, 아래에 **바코드·번호·각주** 인쇄
- 당첨 확인창은 종이에 **다이컷**으로 뚫려 있고, 그 위를 **두꺼운 겉종이(절취면)** 가 덮고 있음
- 겉종이 끝의 탭을 집어 뜯으면 **흰 속지에 찍힌 등급**이 드러남

| 단계 | 화면 | 사운드(ON 시) |
|---|---|---|
| 1 | 가로형 종이 티켓 제시 — 위 색 띠(POKO KUJI·시리즈·1회 포인트), 왼쪽 세로 반치 `くじ券の半券`, 아래 바코드·No.·각주, 가운데는 `당첨 확인부` 종이(ビリビリしよ？ 말풍선 · ? 워터마크 · 점선 미싱선 · 반원 뜯기 탭 `>>>`) — 문구 `오른쪽 끝을 잡아 종이를 뜯어 주세요` | 종이 미끄러지는 마찰 + 짧은 차임 |
| 2 | 탭을 손가락/마우스로 왼쪽으로 당기면 겉종이가 **오른쪽부터 뜯기며** 흰 속지와 등급이 드러남 — 경계에는 말려 올라온 종이 단면, 문구 `종이 절취선이 드르륵— 뜯기는 중…` | 점선 간격 `드르륵-탁!` (bandpass 노이즈 펄스) |
| 3 | 70% 이상 당기면 남은 겉종이가 날아가고 **등급(A상·J상·last상) + 상품명 + `当せん` 도장**이 공개, 문구 `종이 티켓 개봉 완료!` | `쫙!` + 등급대별 결과음 → 당첨 팡파레 |

**결과음 3단 (전기 상승음 제거)**

| 등급대 | 사운드 |
|---|---|
| 하위상 F~L | 고무도장 `탁!` + 아케이드 코인 `띠링~` 2음 |
| 중위상 C~E | 오락실 3연타 `띡-띡-띡!` + 밝은 팡파레 |
| 상위상 B·A·LAST | 폭죽 `펑!` + 웅장한 잭팟 화음 팡파레 + 코인 샤워 `촤르르` |

- 윙— 하고 주파수가 올라가던 신스(sawtooth sweep)와 전기 잡음은 전부 삭제했습니다.
- iOS Safari 무음/자동재생 정책: `뜯기` 클릭·드래그 시작(`pointerdown`)마다 `AudioContext.resume()` 이 걸리도록 처리.
- **뜯긴 결** — 겉종이가 뜯긴 경계의 미세한 지그재그는 뽑기마다 새로 생성되어 매번 다릅니다.
- **등급 인쇄** — 등급은 실제 티켓처럼 잉크색 큰 글씨로 찍히고, 아래에 등급 색 띠 · 상품명 · `当せん` 도장 · No.가 함께 인쇄됩니다.
- **대체 조작** — 티켓 탭, `뜯기` 버튼, `Enter`/`Space` 로도 같은 연출이 재생됩니다(접근성·편의).
- **여러 장** — `x5`·`x10`·`ALL` 은 티켓을 **한 장씩** 넘기며 뜯고, 상단에 `1 / 5` 로 진행을 표시합니다. 뜯은 등급은 하단 칩으로 쌓입니다.
- **한 번에 다 뜯기 (SKIP)** — 우측 상단 `SKIP >>` 또는 하단 `한 번에 다 뜯기 SKIP` 을 누르면 남은 티켓을 건너뛰고 곧바로 결과 모달로 넘어갑니다.
- **중복 차감 없음** — 당첨 결과는 연출 시작 전에 한 번만 확정되므로 스와이프·탭·스킵·연타 어느 쪽이든 포인트 차감과 지급은 정확히 1회입니다.
