# 포코쿠지 (POKO KUJI)

치이카와 감성의 **4개 시리즈 × 진열대형 상세 뽑기** 모바일 웹 데모입니다.
포코쿠지 시그니처 테마의 4열 진열대(등급 스티커 라벨·실시간 확률·밀랍 실링 완판 도장) 상세 화면과
시리즈별 30개 박스 교체, `x1 / x5 / x10 / ALL` 뽑기, 진열장·묶음 배송·사장님 모드를 담았습니다.

- 단일 파일(`index.html`)로 동작하며 외부 CDN·폰트·이미지에 의존하지 않습니다. (모든 일러스트는 인라인 SVG)
- 모바일 기준 420px 프레임, 데스크톱에서는 중앙 정렬로 표시됩니다.
- 결제·배송은 **데모로만** 동작하며 실제 청구나 발송은 없습니다.
- 상태는 메모리에만 있고 새로고침하면 초기화됩니다.

## 시그니처 테마 — "크림 캔디 가챠" (2026-11-27 리뉴얼)

쿠지맨류의 검정·보라 네온 톤에서 벗어나 포코쿠지만의 시각 언어로 전면 교체했습니다.
**정보 구조**(4열 진열대·잔여 수량·실시간 확률·박스 교체·`x1/x5/x10/ALL`)와 캡슐 낙하 연출·사운드는 그대로이고, 색·질감·모양만 바뀌었습니다.

- **팔레트** — 크림 파치먼트 `#FFF7EC` · 코랄 피치 `#F0684B` · 민트 `#38B394` · 버터 `#FFC24B` · 딥 플럼 `#3B1730`
- **홈 헤더** — 캔디 캐노피 그라데이션 + 스캘럽 종이 가장자리 + 도트 그레인 + 캡슐 브랜드 마크
- **배너 · 인포바** — 잉크 테두리 종이 티켓, 천공선(dashed) 디테일, 모노스페이스 영수증 숫자
- **등급 표기** — 등급색 바탕 + 잉크 글자의 *스티커 라벨* 하나로 통일 (진열대·랭킹·기록·진열장·결과 모달)
- **완판 도장** — 빨간 사각 스탬프 대신 원형 **밀랍 실링**(`SOLD OUT` / `종료`)
- **진열대 카드** — 크림 종이 카드 + 도트 그레인, A상은 **쿠폰 커트선**, last상은 **이중 잉크 링**
- **뽑기 버튼** — 코랄·민트·버터·플럼 **젤리 캡슐 돔** (3D 눌림 손맛 유지)
- **상세 스테이지** — 네이비 그리드 대신 딥 플럼 + 코랄·민트·버터 스포트라이트 빔
- **뽑기 연출** — 보라 네온 캐비닛 대신 잉크 테두리 **크림 캔디 캐비닛**, 캡슐 낙하·빛 폭발은 그대로
- **아이콘** — 진열장 계열 아이콘을 시그니처 **캡슐** 라인 아이콘으로 교체

## 화면

1. **홈** — 4개 시리즈 카드(남은 티켓·판매율), 포인트, 진열장 바로가기
2. **상세 뽑기**
   - 상단: `P 6,200/회` · `교체` · `28/30 박스` · `잔여량 98/199`
   - 박스 전환: `<` `>` 및 박스 목록(30개, 박스마다 **별도 잔여 수량**)
   - 서브탭: `상품` / `랭킹` / `기록`(실시간 뽑기 로그)
   - 4열 진열대: `last상(증정품)` + `A~J상`, 등급 배지 · 실시간 확률 · 잔여 `1/2` · 기준 포인트
   - 잔여 0 등급은 빨간 **종료** 도장, 잔여 0 박스는 모든 버튼 잠금(완판)
   - 하단: `x1` `x5` `x10` `ALL`(1회 뽑기 후 해금, 잔여 티켓 전체)
3. **진열장** — 뽑은 굿즈 목록(등급·박스·시간·포인트), 선택 후 **묶음 배송**(`CH-YYYYMMDD-001` 접수번호)
4. **사장님** — 총 매출·판매/잔여 티켓·진열장·배송 KPI, 시리즈별 매출/재고/리셋, 최근 뽑기 기록

## 아케이드 연출 (2026-11-27 업그레이드)

4열 진열대의 정보 가독성(확률·잔여·종료 도장·상품명)은 그대로 두고 오락실 감성을 더했습니다.

- **홈** — 네온 잭팟 글로우, 회전하는 하이라이트 광선, 스파클 파티클, 골드 LED 마퀴,
  시리즈 카드 shimmer + 등급별 네온 포인트
- **상세 상단** — 회전하는 3색(마젠타·시안·골드) 스포트라이트 빔, LED 전광판 정보 바
  (`P 6,200/회 · 교체 · 잔여량`), 실시간 LED 티커
- **진열대** — `A상`·`last상` 카드에 골드/홀로그램 쉬머 테두리(내용 위에 겹치지 않음)
- **뽑기 버튼** — 색상별 3D 푸시버튼, `:active` 눌림 탄성
- **뽑기 연출** — 캡슐 낙하 `0.62초` → 등급별 빛 폭발(J 블루·화이트 / D~G 퍼플 /
  A~C 골드 / last 레인보우) → `0.88초`에 결과 모달. 화면 탭·`건너뛰기`·`ESC`로 스킵
- **사운드** — 상단 🎵 토글(기본 ON). 첫 터치에서 AudioContext unlock 후
  버튼·캡슐·당첨 팡파레를 Web Audio 신스로 재생(외부 음원 없음)

## 뽑기 규칙

- 등급별 잔여 수량 가중치로 당첨 등급을 뽑고, 뽑은 만큼 잔여·확률이 즉시 갱신됩니다.
- 박스의 마지막 티켓이 소진되면 **라스트상이 자동 지급**되고 결과 모달에 표시됩니다.
- `ALL`은 해당 박스의 잔여 티켓을 모두 뽑습니다(포인트 부족 시 샘플 충전 후 이어서 진행).
- 포인트는 240,000P로 시작하며 부족하면 데모 충전(+120,000P 이상)으로 채웁니다.

## 검증

`verify.py` — Playwright(420×900)로 홈 4시리즈 → 상세 진입 → 박스 교체(개별 잔여) →
`x1`/`x5` 뽑기와 포인트·확률 변동 → 교토 `ALL` 완판·라스트상 자동 지급 →
종료 도장 → 진열장·묶음 배송 접수번호 → 사장님 집계·리셋 → 콘솔 오류 0건을 확인합니다.
`shots.py` / `shots_arcade.py` — 발표용 스크린샷(`shots/`, `shots/arcade/`).

```bash
export LD_LIBRARY_PATH=/workspace/.libs/usr/lib/x86_64-linux-gnu:/workspace/.apt/root/usr/lib/x86_64-linux-gnu:$LD_LIBRARY_PATH
python3 verify.py            # 로컬 파일 검증
python3 verify.py https://whaldus960-del.github.io/chiishop-kr/   # 라이브 검증
python3 shots.py https://whaldus960-del.github.io/chiishop-kr/
```
