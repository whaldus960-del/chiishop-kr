# 치이샵 (CHII SHOP)

치이카와 감성의 **온라인 쿠지(뽑기) 숍** 모바일 웹 데모입니다.

- 단일 파일(`index.html`)로 동작하며 외부 CDN·폰트·이미지에 의존하지 않습니다.
- 모바일 기준 420px 프레임, 데스크톱에서는 중앙 정렬로 표시됩니다.
- 결제·배송은 **데모로만** 동작하며 실제 청구나 발송은 없습니다.
- 티켓은 꽝 없이 100% 당첨, 등급별 잔여 수량과 확률을 실시간으로 공개합니다.

## 화면

1. **홈** — 진행 중 쿠지, 오픈 예정 쿠지 라인업(알림 신청), 실시간 경품 현황, 공지
2. **뽑기** — 티켓 오픈 연출, 결과 모달, 보관함 자동 저장, 라스트원상 연출
3. **보관함** — 당첨 상품 선택 후 묶음 배송 신청(연락처·주소 입력), 접수번호 발급
4. **사장님 모드** — 누적 매출, 판매/남은 티켓, 등급별 재고, 뽑기 로그

## 데모 규칙

- 총 80장 = A상 2 · B상 4 · C상 8 · D상 16 · E상 50 (꽝 없음)
- 시작 상태: 38장 판매 완료 · 42장 남음 · 누적 매출 456,000원
- 포인트는 샘플 240,000P로 시작, `＋ 충전`으로 120,000P씩 충전
- 모든 상태는 메모리에만 있고 새로고침하면 초기화됩니다

## 실제 서비스 전 확인할 것

- 경품류 제공 영업 신고 등 국내 규제 검토, PG 심사용 확률 공개·최소 보장 구조
- 당첨 상품의 환금성 차단(현금·포인트 환급 금지)과 청소년 이용 제한
- 캐릭터·브랜드 라이선스: 마스코트는 직접 그린 임시 일러스트이며 실제 캐릭터 사용은
  라이선스가 필요합니다. `치이샵` 상호·상표도 사용 전 확인이 필요합니다.
- 재고·당첨 결과의 서버 저장, 관리자 로그인, 배송·송장 연동
