# 포코쿠지 (POKO KUJI)

치이카와 감성의 **4개 시리즈 × 진열대형 상세 뽑기** 모바일 웹 데모입니다.
포코쿠지 시그니처 테마의 4열 진열대(등급 스티커 라벨·실시간 확률·밀랍 실링 완판 도장) 상세 화면과
시리즈별 **3박스**(박스당 99장) 교체, `x1 / x5 / x10 / ALL` 뽑기, 진열장·묶음 배송·사장님 모드를 담았습니다.

- 단일 파일(`index.html`)로 동작하며 외부 CDN·폰트·이미지에 의존하지 않습니다. (모든 일러스트는 인라인 SVG)
- 모바일 기준 420px 프레임, 데스크톱에서는 중앙 정렬로 표시됩니다.
- 결제·배송은 **데모로만** 동작하며 실제 청구나 발송은 없습니다.
- 상태는 메모리에만 있고 새로고침하면 초기화됩니다.

## 실DB(Supabase) 모드

같은 폴더의 `config.js` 에 `SUPABASE_URL` / `SUPABASE_ANON_KEY` 를 넣으면
자동으로 **실서비스 모드**로 전환됩니다 (로그인·서버 뽑기·진열장·배송·재고 공유).
비어 있으면 지금까지의 데모 그대로입니다. `index.html?demo=1` 로 강제 데모도 가능합니다.

- `supabase-client.js` — `window.CHII_BACKEND` 어댑터 (외부 라이브러리 없이 `fetch` 만)
- `config.js` — 접속 설정 (키를 넣는 곳)
- 스키마·시드·설치 절차: **`../chiishop-backend/SETUP.md`**

데모 검증은 그대로 `verify.py` (config 가 비어 있으면 146개 체크 전부 데모 경로).

## 실제 이치방쿠지 「くじ券」 티켓 — 페리페리 필름 뜯기 (2026-11-27 v3)

세로 카드(봉투) 모양이던 연출을, 실제 일본 이치방쿠지 종이 티켓(一番くじ くじ券)의 생김새로 전면 교체했습니다.
실물 사진과 공식 구조도(外側·内側)를 확인해 형태·인쇄 요소를 맞췄습니다.

**실물에서 확인한 구조**

- 크림·크래프트 종이의 **가로형(약 1.5:1) 2겹 티켓**. 왼쪽에 **반치(半券) 세로 띠 + 미싱선**, 아래에 **바코드·번호·각주** 인쇄
- 당첨 확인창은 종이에 **다이컷**으로 뚫려 있고, 그 위를 **인쇄 필름(페리페리면)** 이 덮고 있음
- 필름 끝의 탭을 집어 뜯으면 **흰 속지에 찍힌 등급**이 드러남

| 단계 | 화면 | 사운드(ON 시) |
|---|---|---|
| 1 | 가로형 종이 티켓 제시 — 위 색 띠(POKO KUJI·시리즈·1회 포인트), 왼쪽 세로 반치 `くじ券の半券`, 아래 바코드·No.·각주, 가운데는 `당첨 확인부` 필름(ペリペリしよ？ 말풍선 · ? 워터마크 · 점선 미싱선 · 반원 뜯기 탭 `>>>`) | 종이 넘기는 소리 + 짧은 차임 |
| 2 | 탭을 손가락/마우스로 오른쪽으로 밀면 필름이 **오른쪽부터 벗겨지며** 흰 속지와 등급이 드러남 — 경계에는 말려 올라온 필름 단면 | 지직거리는 마찰음(루프) |
| 3 | 60% 이상 밀면 남은 필름이 날아가고 **등급(A상·J상·last상) + 상품명 + `当せん` 도장**이 공개 — 섬광·광선·종이 콘페티 | `찌직-` + 등급별 폭발음 → 당첨 팡파레 |

- **뜯긴 결** — 필름이 벗겨진 경계의 미세한 지그재그는 뽑기마다 새로 생성되어 매번 다릅니다.
- **등급 인쇄** — 등급은 실제 티켓처럼 잉크색 큰 글씨로 찍히고, 아래에 등급 색 띠 · 상품명 · `当せん` 도장 · No.가 함께 인쇄됩니다.
- **대체 조작** — 티켓 탭, `뜯기` 버튼, `Enter`/`Space` 로도 같은 연출이 재생됩니다(접근성·편의).
- **여러 장** — `x5`·`x10`·`ALL` 은 티켓을 **한 장씩** 넘기며 뜯고, 상단에 `1 / 5` 로 진행을 표시합니다. 뜯은 등급은 하단 칩으로 쌓입니다.
- **한 번에 다 뜯기 (SKIP)** — 우측 상단 `SKIP >>` 또는 하단 `한 번에 다 뜯기 SKIP` 을 누르면 남은 티켓을 건너뛰고 곧바로 결과 모달로 넘어갑니다.
- **중복 차감 없음** — 당첨 결과는 연출 시작 전에 한 번만 확정되므로 스와이프·탭·스킵·연타 어느 쪽이든 포인트 차감과 지급은 정확히 1회입니다.
- 검증: `verify_draw.py [URL]` — 53개 체크(스와이프 · 살짝 밀었다 놓기 · 티켓 탭 · `뜯기` 버튼 · SKIP · x5 한 장씩 · x10 한 번에 · 콘솔 0건).

## 뽑기 버튼 — 총 차감 포인트 즉시 표시

- `x1 · x5 · x10 · ALL` 버튼 서브텍스트가 `총 6,200P / 31,000P / 62,000P` 로 **총 차감 포인트**를 바로 보여줍니다.
- 버튼 위 한 줄에 `보유 P 240,000 · x1 6,200P · x5 31,000P · x10 62,000P` 를 함께 노출합니다.
- 포인트가 모자란 버튼에는 `부족` 배지가 붙습니다.

## 박스 교체 — 한눈 비교

- 각 박스 행에 `총 잔여 N/199장` · `상위 A·B N장` · `라스트까지 N장`(라스트상이 이미 나갔으면 `지급완료`)을 함께 표시합니다.
- 상위상(A·B) 잔여가 가장 많은 박스에 `전략픽` 배지를 붙여 고르기 쉽게 했습니다.

## 진열장 — 묶음배송 무료 게이지

- 상단에 `묶음배송 3점 이상 무료 · 현재 N/3점` 진행 바를 두고, 3점을 넘으면 민트색으로 바뀌며 "무료배송 조건 달성" 안내로 바뀝니다.

- `og-pokokuji.png`(1200×630, 사이트와 같은 크림 캔디 톤)를 사이트 루트에 두고 `og:image` · `twitter:image`(`summary_large_image`)에 절대 URL(`https://whaldus960-del.github.io/chiishop-kr/og-pokokuji.png`)로 연결했습니다.

## 뽑기 규칙

- 등급별 잔여 수량 가중치로 당첨 등급을 뽑고, 뽑은 만큼 잔여·확률이 즉시 갱신됩니다.
- 박스의 마지막 티켓이 소진되면 **라스트상이 자동 지급**되고 결과 모달에 표시됩니다.
- `ALL`은 해당 박스의 잔여 티켓을 모두 뽑습니다(포인트 부족 시 샘플 충전 후 이어서 진행).
- 포인트는 240,000P로 시작하며 부족하면 데모 충전(+120,000P 이상)으로 채웁니다.
