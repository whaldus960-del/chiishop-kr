### ④ 출고하기 시트 (`r_04` 스타일)

진열장에서 상품을 고르고 `출고하기`를 누르면 뜨는 시트를 실전형으로 바꿨습니다.

- **배송지** — 저장된 기본 주소 표시 / 없으면 `주소를 입력해주세요`, `주소 선택 >`으로 배송지 시트(저장·선택·삭제)
- **상품 목록** — 썸네일 · 상품명 · `판매가 P 00,000` · 수량 `− 1 +` · 휴지통 삭제 · `해외배송 · 통관 필요` 배지
  - 같은 상품이 여러 점이면 한 줄로 묶여 수량이 됩니다. `+`는 같은 상품의 미선택 재고가 있을 때만 열립니다.
- **통관 정보** — `이름 (신분증과 동일한 이름)` + `PCCC (P로 시작하는 13자리)` + `?` 도움말
- **하단 바** — 총 금액(3점 이상 무료 / 미만 3,500원) · `배송 안내` · `배송 확인`
- **검증** — 주소·이름·PCCC 형식·동의가 모두 맞아야 `배송 확인`이 열리고,
  접수하면 `CH-YYYYMMDD-001` 번호가 생기며 마이페이지 `출고 완료`·배송 내역에 바로 쌓입니다.
- PCCC는 데모에서 **저장하지 않습니다**(입력값은 화면 메모리에만).

**실물에서 확인한 구조**

- 당첨 확인창은 종이에 **다이컷**으로 뚫려 있고, 그 위를 **두꺼운 겉종이(절취면)** 가 덮고 있음
- 겉종이 끝의 탭을 집어 뜯으면 **흰 속지에 찍힌 등급**이 드러남

| 단계 | 화면 | 사운드(ON 시) |
|---|---|---|
| 1 | 가로형 종이 티켓 제시 — 위 색 띠(POKO KUJI·시리즈·1회 포인트), 왼쪽 세로 반치 `くじ券の半券`, 아래 바코드·No.·각주, 가운데는 `당첨 확인부` 종이(ビリビリしよ？ 말풍선 · ? 워터마크 · 점선 미싱선 · 반원 뜯기 탭 `>>>`) — 문구 `오른쪽 끝을 잡아 종이를 뜯어 주세요` | 종이 미끄러지는 마찰 + 짧은 차임 |
| 2 | 탭을 손가락/마우스로 왼쪽으로 당기면 겉종이가 **오른쪽부터 뜯기며** 흰 속지와 등급이 드러남 — 경계에는 말려 올라온 종이 단면, 문구 `종이 절취선이 드르륵— 뜯기는 중…` | 점선 간격 `드르륵-탁!` (bandpass 노이즈 펄스) |

| 등급대 | 사운드 |

- **여러 장** — `x5`·`x10`·`ALL` 은 티켓을 **한 장씩** 넘기며 뜯고, 상단에 `1 / 5` 로 진행을 표시합니다. 뜯은 등급은 하단 칩으로 쌓입니다.
- **한 번에 다 뜯기 (SKIP)** — 우측 상단 `SKIP >>` 또는 하단 `한 번에 다 뜯기 SKIP` 을 누르면 남은 티켓을 건너뛰고 곧바로 결과 모달로 넘어갑니다.
- **중복 차감 없음** — 당첨 결과는 연출 시작 전에 한 번만 확정되므로 스와이프·탭·스킵·연타 어느 쪽이든 포인트 차감과 지급은 정확히 1회입니다.
- 검증: `verify_draw.py [URL]` — 53개 체크(스와이프 · 살짝 밀었다 놓기 · 티켓 탭 · `뜯기` 버튼 · SKIP · x5 한 장씩 · x10 한 번에 · 콘솔 0건).

## 뽑기 버튼 — 총 차감 포인트 즉시 표시

- `x1 · x5 · x10 · ALL` 버튼 서브텍스트가 `총 6,200P / 31,000P / 62,000P` 로 **총 차감 포인트**를 바로 보여줍니다.
- 버튼 위 한 줄에 `보유 P 240,000 · x1 6,200P · x5 31,000P · x10 62,000P` 를 함께 노출합니다.
- 포인트가 모자란 버튼에는 `부족` 배지가 붙습니다.

## 박스 교체 — 한눈 비교

- 각 박스 행에 `총 잔여 N/199장` · `상위 A·B N장` · `라스트까지 N장`(라스트상이 이미 나갔으면 `지급완료`)을 함께 표시합니다.
- 상위상(A·B) 잔여가 가장 많은 박스에 `전략픽` 배지를 붙여 고르기 쉽게 했습니다.

## 진열장 — 묶음배송 무료 게이지

- 상단에 `묶음배송 5개 이상 무료 · 현재 N/5개` 진행 바를 두고, 5개를 넘으면 민트색으로 바뀌며 "무료배송 조건 달성" 안내로 바뀝니다.

## 공유 미리보기 (OG)

- `og-pokokuji.png`(1200×630, 사이트와 같은 크림 캔디 톤)를 사이트 루트에 두고 `og:image` · `twitter:image`(`summary_large_image`)에 절대 URL(`https://whaldus960-del.github.io/chiishop-kr/og-pokokuji.png`)로 연결했습니다.

## 뽑기 규칙

- 등급별 잔여 수량 가중치로 당첨 등급을 뽑고, 뽑은 만큼 잔여·확률이 즉시 갱신됩니다.
- 박스의 마지막 티켓이 소진되면 **라스트상이 자동 지급**되고 결과 모달에 표시됩니다.
- `ALL`은 해당 박스의 잔여 티켓을 모두 뽑습니다(포인트 부족 시 샘플 충전 후 이어서 진행).
- 포인트는 240,000P로 시작하며 부족하면 데모 충전(+120,000P 이상)으로 채웁니다.
