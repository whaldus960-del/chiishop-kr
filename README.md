# 치이샵 (CHII SHOP)

치이카와 감성의 **다중 쿠지(이치방쿠지) · 카드샵(TCG) 모바일 웹** 데모입니다.
쿠지맨 스타일의 카탈로그 그리드 + 상품별 뽑기 상세 화면 구조입니다.

- 단일 파일(`index.html`)로 동작하며 외부 CDN·폰트·이미지에 의존하지 않습니다. (썸네일은 전부 인라인 SVG)
- 모바일 기준 420px 프레임, 데스크톱에서는 중앙 정렬로 표시됩니다.
- 결제·배송은 **데모로만** 동작하며 실제 청구나 발송은 없습니다.
- 상품마다 티켓 풀·등급별 잔여 수량·확률이 **독립**으로 돌아가고, 꽝 없이 100% 당첨입니다.

## 화면

1. **홈** — 🎀 제일 복권 8종(4열 2줄) + 🃏 카드샵 8종(4열 2줄), 실시간 상품명 검색, 포인트 충전, 진열장
2. **상점** — 전체 16종 + 카테고리 필터(전체 / 제일 복권 / 카드샵), 검색 연동
3. **상세 뽑기** — `← 뒤로`, 상품 히어로, 등급별 잔여·실시간 확률, 1회/5회 연속 뽑기, 라스트원상(NON-LAST 상품은 없음)
4. **진열장** — 16개 상품에서 뽑은 상품이 한곳에 쌓이고, 선택 후 묶음 배송 신청(접수번호 발급)
5. **사장님 모드** — 전체 누적 매출, 카테고리별 매출, 상품별 재고·매출 16줄, 최근 뽑기 기록, 전체 리셋

## 상품 구성

| 구분 | 상품 | 가격(P) |
|---|---|---|
| 제일 복권 | 치이카와 스위츠 / 모구모구 본점 / 하치와레 파자마 / 쿠리만주 카페 / 산리오 스위츠 / 모몬가 / 우사기 피크닉 / 랏코 온천 | 12,000 ~ 17,000 |
| 카드샵 | 원피스 신의 시대 / 포켓몬 닌자 스피너 / 테라스탈 페스타 / 드래곤볼 슈퍼 카드 / 유희왕 오버드라이브 / 포켓몬 151 부스터 / 원피스 카드샵 한정 / 포켓몬 스칼렛 EX | 1,400 ~ 9,900 |

- 제일 복권은 A~E 5등급, 카드샵은 SAR·SR·AR·RR·C(또는 UR·R) 5등급으로 구성됩니다.
- `NON-LAST` 상품(드래곤볼 슈퍼 카드, 원피스 카드샵 한정)은 라스트원상이 없습니다.
- 포인트는 샘플 240,000P로 시작, `＋` 배지를 누르면 120,000P씩 충전됩니다.
- 모든 상태는 메모리에만 있고 새로고침하면 초기화됩니다.

## 검증

`verify.py` — Playwright(420×900)로 홈 8+8 그리드, 검색 필터, 카드→상세 진입, 1회/5회 뽑기와 상품별 독립 차감,
라스트원상 지급, 진열장·묶음 배송, 사장님 집계, 콘솔 오류 0건을 확인합니다.
`shots.py` — 발표용 스크린샷.

```bash
export LD_LIBRARY_PATH=/workspace/.libs/usr/lib/x86_64-linux-gnu:/workspace/.apt/root/usr/lib/x86_64-linux-gnu:$LD_LIBRARY_PATH
python3 verify.py
python3 shots.py
```

## 실제 서비스 전 확인할 것

- 경품류 제공 영업 신고 등 국내 규제 검토, PG 심사용 확률 공개·최소 보장 구조
- 당첨 상품의 환금성 차단(현금·포인트 환급 금지)과 청소년 이용 제한
- 캐릭터·브랜드 라이선스: 썸네일은 직접 그린 임시 일러스트이며 실제 캐릭터 사용은
  라이선스가 필요합니다. `치이샵` 상호·상표도 사용 전 확인이 필요합니다.
- 재고·당첨 결과의 서버 저장, 관리자 로그인, 배송·송장 연동
